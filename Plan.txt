План разработки: ипотечный калькулятор
======================================

Этап 1. Математическое ядро (src/js/calculations)
  [x] decimal.js     — точный разбор десятичных чисел, округление half up на BigInt
  [x] money.js       — копейки, форматирование, даты (UTC, прижимание дня к концу месяца)
  [x] mortgageMath.js — месячная ставка p/q, аннуитет, дифф. платёж, график,
                        обратные задачи (точно по копейкам, бинарный поиск)
  [x] validate.js    — проверка ввода, лимиты, нормализация
  [x] mortgage.js    — режимы «по стоимости» / «по платежу», годовая агрегация

Этап 2. Проверка ядра (tests, scripts/gen_golden.py)
  [x] Эталон на Python Fraction → golden.json, сверка до копейки
  [x] Инварианты на случайных входах (ГПСЧ с seed)
  [x] Граничные значения: 0 %, 100 %, 1 месяц, 50 лет, 100 млрд ₽

Этап 3. Интерфейс (src/index.html, css, app.js)
  [x] Вкладка «Ипотека», два режима, форма слева / результаты справа
  [x] Взнос в ₽ и в % с конвертацией, срок в годах и месяцах
  [x] Ошибки на лету, aria-атрибуты, светлая/тёмная тема

Этап 4. Графики и таблица
  [x] Остаток долга + проценты, платежи по годам, структура расходов
  [x] График платежей по годам / по месяцам

Этап 5. Экспорт
  [x] PDF (векторные графики, кириллица), Excel (числа, 3 листа)

Этап 6. Качество
  [x] ESLint, jsdom smoke-тест, статические проверки
  [x] GitHub Actions: lint + тесты + воспроизводимость golden
